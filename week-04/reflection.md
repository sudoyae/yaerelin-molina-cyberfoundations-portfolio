## Prompts

**What clicked for you this week?**

```
The numbers in chmod clicked when I realized each permission has a value: read is 4, write is 2, and execute is 1. You add the values for the access you want to give each audience. For example, 7 means read, write, and execute (4 + 2 + 1), while 5 means read and execute (4 + 1). That helps me understand what a setting like 755 actually allows for the owner, group, and others.
```

**What's still confusing?**

```
I’m still practicing when to use chmod, an ACL, or chown because they all affect access in different ways. For example, if a report belongs to me, I could use chmod to let its group read it. If just one person outside that group needs to read it, I could add an ACL entry for that person. If someone else should become the report’s owner, I would use chown. I understand each command separately, but I need more practice choosing the right one for a specific situation.when access doesn’t work as expected.
```

```
This week helped me see how file permissions support that goal. For example, staff need access to do their jobs, but sensitive records and system settings should only be available to people who need them. **One thing you'd tell a friend just starting this course?**
```
