**What is the cybersecurity landscape, and why does it matter?**

```
The cybersecurity landscape is a big picture that consists of digital systems, who attacks them, and how both sides adapt to be interconnected. The more connected devices, the larger the attack surface. 
```

**How do hardware, OS, and software layers interact?**

```
The software layer communicates with the operating system whenever it needs to perform a task, such as accessing the internet. The operating system manages these requests and tells the hardware, such as the CPU, RAM, and storage, what to do. After the hardware completes the work, the results are sent back through the operating system to the software so that I can use the Google Chrome application. 
```

**One term I want to remember from this week, and why:** kernal_task

```
I want to remember kernal_task because it is a core operating system process that manages communication between macOS and the hardware. It helped me understand how the operating system controls hardware sources such as the CPU and memory while applications run.
```
