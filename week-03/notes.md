## In My Own Words

**What's the difference between a file and a folder, and how do they form a tree together?**
While a file is a piece of digital data stored on a computer, a folder is a container used to organize that data and other folders. The root directory is like the trunk, folders are the branches that split into smaller branches (subfolders), and files appear at the ends of the branches. Altogether, they form a tree structure. 

**How does a Windows-style file path differ from a Linux-style file path?**
Windows has one home directory for each user. Unlike Windows, Linux does not use drive letters. Everything starts from a single root directory (/) and attached within the same directory tree. For example, Windows user home directories are under "C:\Users\" while Linux user home directories are under "/home/".
